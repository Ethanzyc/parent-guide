parent-guide
跑在你自己 AI 里的育儿顾问

基于 CDC / AAP 等公开指南整理的育儿参考 + 习惯追踪闭环 + 成长视图。
没有云端、没有账号——孩子的一切数据,只存在你自己的电脑上。

🎯 分档回答,不写大作文

紧急场景给 ≤150 字当下动作卡;习惯养成给完整计划并自动记录、到期回访效果。答案标注口径来源与证据分级,不确定就明说。

🔒 数据不出本机

孩子的档案是本地一个 JSON 文件;页面只监听 127.0.0.1;skill 只读 data/ 目录。没有遥测,没有上传。

🧩 带走你的 AI,装进育儿能力

标准 Agent Skills 格式,zcode / Claude Code / OpenClaw / Claude 桌面端等 47+ 宿主通用;配套本地成长视图与可转发的单文件报告。

GitHub 获取源码 先逛在线知识库 → 三步安装 →

安装:clone 后 cp -R skills/parent-guide ~/.zcode/skills/, 再 cp skills/parent-guide/data-templates/child.json data/ 建档; 页面 python3 server.py --open。详见仓库 README。

本产品提供育儿参考,不构成医疗建议,不替代医生诊断;健康问题请咨询专业医生。 里程碑内容源自 CDC「Learn the Signs. Act Early.」(公有领域)中文化,不构成 CDC 背书。 部分内容由 AI 辅助生成,关键内容经人工与官方来源核对(AIGC 已标识)。
