## 入库检查(新文件必过)

任何新知识文件入库走三件套(协议见 skill `references/knowledge-index.md` §5,
发布门 `scripts/publish.sh` 自动把关):

1. **三要素留档**:头部注明 来源 + 入库日期 + 核对方式(哪些经原文核对、
   哪些是转述)——「未核对不入库」;健康类(疫苗/剂量)必须经官方原文核对,
   过期口径以入库日期为复查线索;
2. **引用对账**:`bash skills/parent-guide/scripts/audit-citations.sh knowledge/<file>.md`
   通过——悬空文件引用、无来源医学断言会被拦下;
3. **官方关系标注**:与官方库同主题文件的关系逐条标注(互补/一致/张力+
   以官方为准的理由),冲突处不悄悄站边。

三件全过才入库;任何一件不过,如实报告而不是硬入。

## 使用方式

skill(skills/parent-guide)按 references/knowledge-index.md §4 路由表按需 See 本目录;
本目录缺失时 skill 走降级协议(只用内置最小知识核)。
知识核速查表与本库口径一致,专题深度以本库为准。
