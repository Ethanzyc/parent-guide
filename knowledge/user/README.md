# 用户自建知识(user/)

这里放**你自己长出来的知识**——不是官方库的一部分,永不随仓库分发:

- **家庭自建笔记**:为孩子特殊需求写的专题(过敏记录/幼儿园适应/5 岁以上
  官方覆盖薄的年龄段);
- **调研转述**:对话中「缺口调研」产出的口径(同主题第二次遇到时,从档案
  锚点升级到这里)。

## 文件头三要素(必留)

    > 自建:YYYY-MM-DD;类型=家庭自建|调研转述;来源=书名/链接/机构;核对=原文级|转述级

## 引用规则

- 引用时标注「家庭自建 T3」,不冒充机构口径;
- 与官方库冲突时以官方为准,并提示核对;
- 只进你本地——`scripts/publish.sh` 排除本目录(本 README 作为约定文档除外)。
