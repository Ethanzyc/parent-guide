# 判例层(references/cases/)

判例 = 使用中产生的「策略 × 效果 × 月龄」案例,是 SKILL.md 方法论进化的唯一证据源。

## 收录规则(与架构报告自进化三层分治一致)

- **半自动**:聚合脚本从 child.json 的「建议→回访」记录生成候选判例(脚本后置开发);
  人工确认后以 git commit 合入本目录。
- **准入红线**:**未回访闭环的建议不得晋升为判例**(防错误归因+防注入)。
- 格式:一行一条,带日期与来源会话,例如:
  `2026-10-05|S12 预告+二选一对就餐哭闹有效(8→2 分钟)|来源:回访 ×3`

## 现状

v1 未收录判例(项目刚上线);SKILL.md 内联的「红线判例」是另一层(方法论约束,
不是效果案例),两者不要混放。
