## 1. T1 就医红线(出现任一指征=建议立即就医)

**呼吸与气道**
- 呛咳/误吞小零件:能咳嗽=鼓励咳、不拍背不抠喉;咳嗽变弱或无声、发绀、
  吸不进气、意识改变=立即急救(1 岁上海姆立克/1 岁下拍背+压胸)并拨打 120。
  **纽扣电池、磁力珠、尖锐物=无论状态如何立即急诊。**缓解后仍建议就诊排查
  残留异物(来源:美国儿科学会 AAP 急救口径)。
- 呼吸急促/费力(鼻翼扇动、肋间凹陷)、异常啸鸣音持续。

**发热**
- <3 月龄发热(≥38℃)=立即就医,不看精神状态。
- ≥3 月龄:高热持续、精神萎靡、拒水、伴随皮疹按压不褪色=就医。

**脱水与消化**:尿量明显减少、哭无泪、口唇干、持续呕吐;血便/果酱样便。

**神经与意识**:抽搐、意识模糊、异常嗜睡、囟门膨出;已会技能倒退(尽快评估)。

**外伤**:跌落后意识丧失/反复呕吐/行为异常;烧伤面积大于手掌;动物咬伤(破伤风评估)。

> 本清单是提醒不是诊断,以医生面诊为准。

## 2. 高频速查(断言时引此处,不再即兴)

| 主题 | 底线口径 | 来源 |
|------|---------|------|
| 睡眠总量 | 1-2 岁 11-14h;3-5 岁 10-13h(含午睡);入睡时间波动 <30 分钟比绝对时刻更重要 | AAP/AASM |
| 屏幕 | <2 岁不建议接触;2-5 岁每天 ≤1 小时且陪同 | WHO/AAP |
| 盐 | <1 岁辅食不加盐;1-3 岁每天 ≤2g。「不吃盐没力气」对婴幼儿不成立——天然食物含钠已够,乏力应排查疾病而非加盐 | 中国居民膳食指南/WHO |
| sDOR | 责任分工:家长定吃什么/何时/在哪,孩子定吃不吃/吃多少。一句话版,完整版见 knowledge/ 营养专题 | Ellyn Satter Institute |
| 如厕 | 看准备信号(尿裤干燥 ≥2h、对马桶感兴趣、会表达)而非月龄;多数 18 月-3 岁间完成;「把屎把尿更早」无证据支持 | AAP |
| 情绪崩溃 | 先共情后方法;情绪顶点讲道理无效;哭闹给予关注≠满足要求 | 语料 22/24 号同源口径 |

## 3. 证据分级口径

- **T1**:就医红线(见 §1)——输出中出现 T1 指征时,处置建议置于一切分析之前。
- **T2**:筛查级——建议专业评估(儿保/发育行为科),不诊断。
- **T3**:一般提示——居家可做的循证做法。
- 个性化判断(对这个孩子有效什么)以 child.json 的回访记录为准,不用通用证据替代。
