# parent-guide · 开源循证育儿顾问

一个跑在你自己 AI 助手里的育儿顾问 skill:基于 CDC/AAP 等公开指南整理的育儿参考,帮你记录孩子成长、制定习惯养成计划并追踪效果。**没有云端、没有账号,孩子的数据只存在你自己的电脑上。**

```
你问:「孩子最近总打别的小朋友,是不是有问题?」
它答:先安心(结合你孩子的记录判断是不是常见行为)→ 给观察方法 →
     什么信号需要找医生 → 一份两周计划,记入档案,到期主动回访效果。
```

## 它能做什么

- **分档回答**:紧急场景(正在哭闹/呛咳)给 ≤150 字的当下动作卡;习惯养成给完整计划;日常给活动建议——不写长篇大作文
- **循证可溯**:断言标注口径来源(CDC/AAP/WHO 等)与证据分级(T1 就医红线/T2 建议评估/T3 居家可做);核内没有的知识明说「不确定」,不编造
- **追踪闭环**:每个计划自动记入孩子档案(strategies+回访日期),下次对话主动回访「上次那招管用吗」——建议效果可以被验证,而不是给完就忘
- **成长视图**:一条命令启动本地页面(拖拽布局的积木卡片:里程碑/睡眠/策略效果/待回访),一键导出可转发的单文件报告

## 快速开始

需要:一个支持 Agent Skills 的 AI 助手(zcode / Claude Code / OpenClaw / Claude 桌面端等 47+ 宿主,或任何能读 Markdown 的 LLM 客户端)+ Python 3(页面功能,可选)。

```bash
git clone https://github.com/Ethanzyc/parent-guide.git && cd parent-guide

# 1) 装 skill 到你的 AI 助手(以 zcode / Claude Code 为例)
cp -R skills/parent-guide ~/.zcode/skills/        # 或 ~/.claude/skills/

# 2) 建立孩子的档案(纯本地,绝不入 git)
mkdir -p data && cp skills/parent-guide/data-templates/child.json data/
#    编辑 data/child.json:孩子小名、生日、当前情况(不会被上传)

# 3) 成长视图(可选)
python3 server.py --open     # 打开 http://127.0.0.1:8765
#    或不开服务:直接双击 web/dist/render.html(文件模式,只读)
```

然后直接问你的 AI 助手育儿问题即可;完整语料库在 `knowledge/`(发育里程碑中文化、睡眠、营养专题),skill 会按需引用。

> **数据与隐私**:所有孩子数据在 `data/` 目录(已被 .gitignore 排除);页面只监听 127.0.0.1;没有任何遥测。skill 只读 `data/` 目录,不碰你机器上的其他文件。

## 仓库结构

| 目录 | 内容 |

| `docs/specs/` | 产品规格与 15 题验收测试集(skill 质量的可复现评测) |
| `tests/` | 服务端测试、技能脚本测试、知识库结构断言 |

## 重要声明

- **本产品提供育儿参考,不构成医疗建议,不替代医生诊断**;就医红线场景它做的是提醒你尽快就医。健康问题请咨询专业医生。
- 发育里程碑内容源自美国疾控中心 CDC「Learn the Signs. Act Early.」检查表(公有领域)的中文化,逐条经 cdc.gov 官方原文核对;不构成 CDC 对本产品的认可或背书。
- **AIGC 声明**:语料整理与代码由 AI 辅助生成,关键内容(如里程碑条目、急救口径)经人工与官方来源核对。
