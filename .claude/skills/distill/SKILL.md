# 知识蒸馏(distill)

> 定位:**调度层**——流程 SSOT 是 `docs/distill-sop.md`(方法/模式/四件套/
> 版权红线/流程全图),本 skill 只做路由与编排,不复制正文(改规则只改 SOP)。
> 沉淀自 2026-09-29 首测(tantrum-cdc.md)与 2026-10-04 语料吸收两轮实战。

## 启动协议

1. **必读**:docs/distill-sop.md 全文(材料在手的先做版权判定);
2. 按用户说法选模式:

| 用户说 | 模式 | 要点 |
|---|---|---|
| 「蒸馏一下」「蒸馏这本书第 X 章」 | **材料蒸馏** | 材料在手;版权受限→自建层,公有领域→官方候选 |
| 「吸收 XX 语料」 | **语料吸收** | 子代理提取公开口径+剔个人信息+标疑点 |
| 「清 BACKLOG」「批量蒸馏」 | **BACKLOG 批量** | 逐待补主题;无来源先缺口调研(research.md 七步) |

3. 执行 SOP §5 流程:版权判定→**防重复扫描**(官方+自建同主题)→蒸馏
   (仓颉精髓+改造规则,见 SOP §2)→**四件套**(第④道引用全审:官方=
   逐断言全审可派 subagent;自建=轻审);
4. 落位:自建层=knowledge/user/ 直接落(头部「自建:」三要素);官方=
   knowledge/ 根目录(闭集,check-knowledge+publish 双侧登记)+**草案与
   审计结果一并呈报,用户拍板才合入**;
5. 官方入库后:BACKLOG 销账→site 重建→docs/knowledge-audit-LOG.md 记一行。

## 铁律(SOP §6 执行位常载版)

- **书摘类永不进官方库**(版权红线);
- **未核对不入库**;疑点引用一律弃用并记录;
- 产物=陈述性知识+口径(不是触发式技能);与官方库关系逐条标注,冲突
  不悄悄站边;
- 官方合入必须「审计前置,人审终审」——草案不带审计结果不进拍板。
